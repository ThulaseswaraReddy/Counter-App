# Counter App (React)
Iam build a beginner level react project (i.e Counter App).A simple and interactive Counter Application built using React to demonstrate the use of state management with the useState hook.
# Features

➕ Increment the counter value
➖ Decrement the counter value (does not go below zero)
🔄 Reset the counter to zero
⚛️ Built with React functional components and hooks

# Outcomes
✔️Understanding React useState hook
✔️Handling events in React
✔️Conditional logic in components
✔️Building reusable and clean UI components

# Technologies Used
👉React
👉JavaScript (ES6)
👉HTML5
👉CSS3
